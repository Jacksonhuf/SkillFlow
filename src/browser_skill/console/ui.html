请从启动器打开

双击技能目录里的 open-console.bat（macOS / Linux：open-console.sh）会自动打开带令牌的页面。若你是手动输入地址，请从启动窗口复制带 ?token= 的链接，或在下方粘贴令牌。

选择要做的任务 高级选项

点一个任务，填好它要求的信息，点「开始运行」。需要登录时会弹出提示，你只需在 Chrome 里登录一次。
