# Universal Browser 0.3.39 升级说明

## 列表页搜索进详情（detail_batch）

- 向导高级选项：**编号不在 URL 中：从列表页搜索再进详情**（示例 URL 填列表页，可不填 URL 模板）。
- 运行时对每个驱动值：打开列表页 → 填写搜索框 → 点查询 → 在结果中打开详情 → 再按原流程采集字段/附件。
- 仍支持整行 **完整详情 URL** 作为驱动值（与列表模式混用）。
