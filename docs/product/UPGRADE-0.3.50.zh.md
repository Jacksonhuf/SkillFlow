# Universal Browser 0.3.50 升级说明

## 向导：Teach 未就绪时禁用录制

- 进入向导第 2/3 步时会读取环境检测中的 **向导录制能力**。
- 若当前引擎缺少 `recommended_operations`（常见于 chrome-use 未实现 `probe.*`），**点选字段 / 展开录制 / 列表导航录制** 按钮会禁用并显示说明；首页「一键修复」切换 Playwright 后自动恢复。
