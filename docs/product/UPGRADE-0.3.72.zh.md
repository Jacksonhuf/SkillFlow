# Universal Browser 0.3.72 升级说明

## 向导试跑：「所有批量项均失败，未产生任何记录」

试跑或正式批量运行时，若每条详情页都失败，以前只显示一句汇总，控制台也容易只看到 FAILED。

**0.3.72 起**：

- 错误信息会带上**第 1 条失败编号**和**可读原因**（缺必填字段、页面未解析出记录、列表进详情失败、需要登录等）。
- 控制台试跑区与「历史结果 → 批量明细」会列出每条失败原因，并给出**建议**（例如重新点选、先登录 Chrome）。
- CLI 在失败时也会从 `error.details` 打印同样的逐条说明。

常见处理：

1. **缺必填字段 / 点选为空**：在向导里重新点选该字段，或取消「必填/主键」后再试跑。
2. **页面未解析出记录**：确认示例地址是**详情页**（不是列表），且 Chrome 已登录。
3. **列表进详情失败**：检查是否录了列表导航、搜索框文案是否与页面一致。
