# Universal Browser 0.3.64 升级说明

## 模板分发可见性

- 控制台模板详情 API 返回 **`delivery_channels`**（类型、目标 URL、是否配置 webhook 密钥，不含密钥明文）。
- 运行面板展示已配置的 Webhook 等分发目标。
- 向导填写 Webhook 时自动启用 **`report.md`** 生成。
- 完整技能包内附带 `docs/product/WEBHOOK-AUTO-RETRY.zh.md`。
